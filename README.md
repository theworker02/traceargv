# traceargv

Trace filesystem argv paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/traceargv/

## Install / run

```bash
git clone https://github.com/theworker02/traceargv.git
cd traceargv
node src/cli.js
node --test
```
